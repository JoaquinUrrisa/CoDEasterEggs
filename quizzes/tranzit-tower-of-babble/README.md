# Tranzit Easter Egg Readiness Tests

Printable quizzes for friends before attempting **Tower of Babble** on Black Ops II Tranzit.

## Contents

| File | Purpose |
|------|---------|
| [index.html](index.html) | Pack cover + links to every test |
| [richtofen/easy.html](richtofen/easy.html) | Richtofen easy (10 Q) |
| [richtofen/medium.html](richtofen/medium.html) | Richtofen medium (12 Q) |
| [richtofen/hard.html](richtofen/hard.html) | Richtofen hard (15 Q) |
| [maxis/easy.html](maxis/easy.html) | Maxis easy (10 Q) |
| [maxis/medium.html](maxis/medium.html) | Maxis medium (12 Q) |
| [maxis/hard.html](maxis/hard.html) | Maxis hard (15 Q) |
| [answer-key.html](answer-key.html) | Host-only answers |
| [score-sheet.html](score-sheet.html) | Maps scores → Recruit / Hardened / Veteran / Realism |

## How to use

1. Open `index.html` in a browser.
2. Print the test that matches your path (**Richtofen** or **Maxis**) and difficulty.
3. Grade with `answer-key.html` (keep this away from the table).
4. Convert scores on `score-sheet.html`.

### Rank thresholds

| Rank | Score % |
|------|---------|
| Recruit | 0–49% |
| Hardened | 50–69% |
| Veteran | 70–89% |
| Realism | 90–100% |

## Print tips

- Use **Print** on each test page (headers/nav hide automatically).
- Print answer key separately for the host.
- Black-and-white printing is fine; layout stays readable.
