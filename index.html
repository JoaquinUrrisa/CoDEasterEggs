How these guides work

  • Written for someone who has never run the Easter Egg before
  • Numbered steps in the order you actually do them
  • Labeled diagrams instead of vague landmark descriptions
  • Checklists that remember where you got to, in your own browser
  • Warnings on the mistakes that quietly end a run
  • Built to be read on a phone with one hand

Contributing

Each guide lives in its own folder with an index.html, a stylesheet, a small script and hand-drawn SVG diagrams. Nothing is built or bundled, so you can open the file directly in a browser and start editing.

Run the whole site locally with python3 -m http.server 8080 from the repository root.
