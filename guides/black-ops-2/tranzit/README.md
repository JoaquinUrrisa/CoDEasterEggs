# TranZit — Tower of Babble

Interactive companion guide for the Black Ops II Zombies TranZit main Easter Egg (**Tower of Babble**).

## Open the guide

Open [`index.html`](./index.html) in a browser (phone or tablet works best while playing).

Or from the repo root with a simple static server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080/guides/black-ops-2/tranzit/`.

## Why this format

This guide is a **mobile-first web page** instead of a long markdown dump because Easter Eggs are easier when you can:

- Switch Maxis / Richtofen paths without scrolling forever
- Check off steps and keep progress in the browser
- See location diagrams next to each step
- Search part locations mid-game
- Jump to the next incomplete step from a sticky bar

## Contents

1. Overview and path choice
2. Beginner requirements and glossary
3. Map / bus route overview (with diagram)
4. Full Maxis walkthrough (setup + egg steps in order)
5. Full Richtofen walkthrough (setup + egg steps in order)
6. Searchable location reference with diagrams
7. Troubleshooting

## Images

Labeled diagrams in [`images/`](./images/) help identify landmarks and part locations without prior map knowledge (bus loop, Turbine depot, cornfield pylon, Power Station hatch, Navcard parts, Jet Gun parts, Avogadro EMP setup, lampposts).
